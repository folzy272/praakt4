# Звіт — практична робота №4 «Основи мови Dart»

**Дисципліна:** Програмування для мобільних платформ.  
**Тривалість:** 2 академічні години (за завданням).  
**Автор:** *впишіть власні ПІБ і групу*.  
**Статус:** вихідні файли, моделі, дані, приклади звітів та тести створено; **виконання Dart не перевірене**, оскільки SDK у робочому середовищі не встановлений.

## Мета

Закріпити синтаксис Dart, типи даних і null safety, функціональне програмування, класи та успадкування, роботу з колекціями й CSV, асинхронні операції та тестування.

## Завдання 1. Структура, Git, README (1 бал)

Створено Dart package `dart_basics_student` із `bin/`, `lib/`, `test/`, `assets/`, `reports/`, `docs/` та `scripts/`. Є `pubspec.yaml`, `.gitignore`, `analysis_options.yaml`, інструкція README та локальний Git репозиторій. Для публічної адреси GitHub власник має створити remote та виконати push.

## Завдання 2. Базові типи і функції (1 бал)

**`bin/task1_variables.dart`** демонструє `int`, `double`, `num`, перетворення типів, арифметику, `String`, escape-послідовності, логіку `bool`, `List`, `Set`, `Map`, nullable-типи `String?`, `??`, `?.`, `late`, `required`. Калькулятор у `lib/utils/calculator.dart` підтримує 6 операцій і запобігає діленню на нуль.

**`bin/task2_functions.dart`** реалізує `calculateSum`, `calculateAverage`, `formatName`, рекурсивні `fibonacci`, `factorial`, замикання `makeCounter`, анонімні функції, `map`, `where`, `fold`. Текстовий аналізатор у `lib/utils/text_analyzer.dart` рахує кількість Unicode-символів, слів, рядків і частотність слів українською та англійською.

## Завдання 3. ООП — система університету (1,5 бали)

**Основні класи:** `Person` (абстрактний), `Student`, `Professor`, `Course`, `University`. Класи `Student` і `Professor` наслідують `Person`. `role`, `fullName`, `age` — спільний інтерфейс; `University.describePeople()` демонструє поліморфізм. Операції: додавання/видалення/пошук студентів, викладачів і курсів; запис студента, виставлення оцінки; перевірка prerequisite; відбір студентів за курсом; пошук доступних курсів; підсумкова статистика.

**Правила:** 0 ≤ оцінка ≤ 100; курс вважається складеним від 60; запис на складний курс відкривається лише за виконання всіх prerequisite; дублікати ID відхиляються. GPA — середній бал за 100-бальною шкалою, без зважування кредитами. JSON перетворення `Student.toJson/fromJson` підтримує `grades`, `enrollmentYear`, `skills`.

UML-діаграма: `docs/university_uml.png`, вихідник `docs/university_uml.dot`.

## Завдання 4. Колекції та аналіз CSV (1 бал)

Файл **`assets/students.csv`** містить 5 навчальних записів. `CsvStudentReader` підтримує CSV із лапками й комами, а поля «курси/оцінки/навички» всередині комірок розділяються `|`. `DataProcessor` надає фільтрацію парних, підрахунок слів, сортування за GPA, об'єднання навичок, перетин курсів, групування за роком вступу, середні бали за курсами й складний звіт по студентах.

## Завдання 5. Асинхронність (0,5 бала)

**`bin/task5_async.dart`** реалізує `fetchStudentData` (симуляція API запиту), `Future.wait`, `timeout`, `try/catch`, `studentStream`, `await for`, `listen`, `loadStudentsFromFile`, `saveStudentsToFile`, асинхронне читання JSON, аналітичну обробку й запис JSON-звіту.

Для трьох затримок по 200 мс програма **вимірює реальний час**, порівнюючи послідовні `await` та конкурентний `Future.wait`. Теоретично паралельний режим коротший (затримки перекриваються); конкретні числа не зазначено, оскільки програма в цьому середовищі не запускалася.

## Тестування, якість і продуктивність

В `test/` створені тести для успішних, граничних та помилкових випадків: оцінки, prerequisites, CRUD, JSON round-trip, калькулятор, українська токенізація, CSV, колекції, Stream, Future. `bin/benchmark.dart` вимірює час двох способів фільтрації 200000 чисел, `Set.intersection`, підрахунок частотності тексту. `scripts/run_all.sh` і `scripts/run_all.ps1` запускають демонстрації й збирають консольні логи.

### Команди для фіксації результатів

```bash
dart pub get
dart format .
dart analyze
dart test --reporter expanded
bash scripts/run_all.sh
dart pub global activate coverage
dart pub global run coverage:test_with_coverage
```

**Статус підтверджень:** скриншоти програм, реальні результати `dart test`/`dart analyze`, LCOV-звіт і GitHub URL **не можуть бути добросовісно наведені без запуску та публікації**. Для цього налаштовано GitHub Actions (`.github/workflows/dart.yml`) — після `push` перевірки зможуть виконатися автоматично. Необхідно переконатися, що CI працює без помилок, і додати реальні артефакти.

## Висновок

У практичній реалізації підготовлено всі п'ять програм, структуру класів, засоби аналізу даних, тестові сценарії та інструкції для відтворення результатів. Найважливішими принципами є null safety, інваріанти даних, поділ відповідальності між шарами, перевірка prerequisites і контрольована асинхронність. Остаточний стан працездатності потрібно підтвердити запуском із Dart SDK і результатами тестів.
